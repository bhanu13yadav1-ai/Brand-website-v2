# BLACKED — Consolidated Final Release (Phases 1–7)

This package is a consolidated working copy based on the audited `bhanu13yadav1-ai/Brand-website-v2` root files, with the Phase 3–7 modules wired into the existing app. It is an additive update, not a replacement template.

## Start here

1. Read `UPLOAD_GUIDE_HINGLISH.md` before updating GitHub Pages.
2. Keep a backup of the current GitHub repository before replacing or uploading files.
3. Extract the ZIP. The `index.html` file is at the ZIP root; do not upload only the ZIP archive as a website file.
4. Upload the extracted site files and folders to the same repository root as the existing `index.html` and commit the change.
5. After Pages finishes rebuilding, open `phase7-diagnostics.html` and press **Run final checks**.
6. Verify the website in Android Chrome using `PHASE7_ANDROID_REGRESSION_CHECKLIST.md`.

## What is connected

- Existing app shell, stories, image archive, wishlist, sample bag, comparison, original three wheels, Dirty/Wild wheel and Fit Studio are preserved.
- Phase 3 collection directory and entry-point polish.
- Phase 4 home/fantasy routes, four additional Hinglish story records with three tone settings, boyfriend preference cards and wheel-to-story links.
- Phase 5 image-failure recovery, product evidence filters, seller-readiness disclosures and a three-item comparison cap. Sales/checkout remain disabled until real evidence and owner approval are supplied.
- Phase 6 wellness diagrams and guidance, collection switching (Sanskari / Noor / Grace), privacy reminders and an image-rights workflow.
- Phase 7 final diagnostics and regression checklist, plus story quick filters and reading controls carried by the existing phase 7–8 enhancement module.

## Important limits

- This is a static front-end prototype. It does not add real accounts, a backend, inventory, orders, payment, seller verification or checkout.
- Existing external image URLs may still fail if their source repo or network is unavailable. The image record/retry controls preserve visibility; live external HTTP availability must be checked after deployment.
- Image rights for existing artwork are **not assumed cleared**. Use `IMAGE_RIGHTS_REGISTER.csv` to document permission before commercial campaigns.
- The 18+ prompt is self-attestation, not formal age verification.
- This package has not been deployed from this environment; GitHub connector writes were blocked. Browser/Android release checks must be run on the uploaded Pages build.
