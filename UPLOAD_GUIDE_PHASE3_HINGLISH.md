# Phase 3 ZIP upload kaise karna hai (simple Hinglish)

**Yeh update ZIP hai, poori website ka replacement nahi.** ZIP ko existing repo ke root mein merge karna hai.

## 1. ZIP extract karo

Phone ke Files app / ZArchiver mein `BLACKED_V3_PHASE3_HORNY_MODE_SPEED_UPDATE.zip` extract karo. ZIP ke andar root par `app.js`, `sw.js`, aur chaar naye root files milenge. Preview aur reports optional documents hain.

## 2. GitHub repo mein files upload karo

Repo: https://github.com/bhanu13yadav1-ai/Brand-website-v2

- Root `app.js` ko naye `app.js` se **replace** karo.
- Root `sw.js` ko naye `sw.js` se **replace** karo.
- Root mein `phase3-horny-mode.js`, `phase3-horny-mode.css`, `phase3-diagnostics.html`, aur `phase3-diagnostics.js` **add** karo.
- `index.html` ko replace mat karna. Naya mode `app.js` se automatically load hota hai.
- Kisi aur file/folder ko delete mat karna. `innerwear-image-library.json`, `size-chart-template.json`, images, purane phase modules, Stories, wheels, wishlist/bag, Wellness aur Fit Studio ko jaisa hai waisa hi rakho.

Agar GitHub mobile upload mein existing files ko overwrite karna mushkil ho, ek-ek file ke editor mein current content replace karke save kar sakte ho. `app.js` aur `sw.js` ka poora content replace hona chahiye; unke end mein sirf extra lines paste kar dena sahi nahi hoga.

## 3. Deployment check

Commit ke baad GitHub Pages build complete hone do. Phir Android Chrome mein site close karke dobara kholo aur zaroorat padne par ek refresh aur karo. **Site storage clear mat karna**, kyunki usse saved local data delete ho sakta hai.

## 4. Diagnostics run karo

Yeh URL kholo:

https://bhanu13yadav1-ai.github.io/Brand-website-v2/phase3-diagnostics.html

`Run all checks` dabao, phir `Measure Home load` run karo aur `Export CSV` se report save kar lo. Diagnostics ka PASS sirf us browser ke checks ka result hai; live site ko mobile par manually bhi test karna hai.

Home par hero ke neeche `SUPER HORNY / RANDI MODE` aana chahiye. Flirty, Teasing, Bold aur Wild change karke dekho; Hinglish/Hindi/English switch karo; Desi Gaali Mode ko on/off karo. Baaki original views, wheels, wishlist/bag, saved stories, archive, Wellness aur Fit Studio ko delete ya replace nahi kiya gaya.
