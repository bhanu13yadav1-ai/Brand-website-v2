# Part A Upload Guide — Hinglish

Target repo: https://github.com/bhanu13yadav1-ai/Brand-website-v2 (branch `main`).

1. Current repo ka backup ZIP/export bana lo.
2. Is package ko Android phone par download karke extract karo.
3. GitHub repo → main → Add file → Upload files kholo.
4. `V1_PART_A_STORIES_FOUNDATION` folder ke **contents** root mein upload karo; ZIP file ko direct upload mat karna aur nested folder mat banana.
5. Matching root files (`index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `README.md`) replace karo; all remaining files add karo. Doosri unrelated files delete mat karna.
6. Commit: `V1 Part A: expand Hinglish story library and filters`.
7. Wait for Pages deployment. Test website then open `/part-a-diagnostics.html` and run Part A checks. Tap “Check image URLs” separately.
8. Physical Android test: Home → Sex Stories 18+ → confirm age → Dirty poll (including Skip) → search → language filter → mood filter → sort → read story → close story. Then verify wheels, innerwear, archive, wellness, saved data and privacy panel.

Note: this package has the full site source, but original 151 visual files are referenced from public source repositories, not embedded. Live image loading must be checked after upload. 18+ is self-attestation only.
