What changed

• Service-worker install now caches only the app shell, feature code and required JSON/SVG resources.

• Images are cached on demand when a same-origin image is requested, instead of 30+ images being fetched during installation.

• The main app no longer fetches its 151-record image manifest or creates the first 24 image cards on the Home visit. It waits until Innerwear opens.

• Four wellness SVG paths now point at the files' actual repository-root locations.

Important: this source-based estimate predicts lower cache-install work. Actual page speed varies by network, device, browser cache and external image hosts; verify using the tests below after upload.
