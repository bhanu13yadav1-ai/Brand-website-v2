Image path & source diagnostics

This page tests the files in the extracted review copy. Run it from a local HTTP server or the deployed preview—not by double-clicking an HTML file if the browser blocks local JSON reads. Browser image errors cannot always distinguish 404, DNS, network restrictions or temporary timeouts.

1. Build / integration checks

Scope boundary: Phase 2 photo galleries are loaded. Phase 3–15 overlays are deliberately not loaded by this review copy.

2. Check bundled local image files

Checks all listed root-level image files from this ZIP, including local campaign and gallery images.

3. Check all 151 remote archive URLs

These images are hosted in three public GitHub repositories. This optional check uses your browser's network. The code reports “load failed” rather than assuming every error is a missing file.

4. How to read the result

PASS = the image loaded and has non-zero dimensions. LOAD FAILED = not loaded from this browser; check connection, policy/CSP, URL or source repository before calling it a 404. NOT TESTED = the test has not been run.

The diagnostic does not upload your saved data. It requests image URLs when you run the remote test. Do not share the report publicly if you don't want to publish your tested image URL list.
