# Phase 4 ZIP — Android se upload ka sahi tareeka

## Pehle bug samjho
Tumhare `Brand-website-v2` repo mein Phase 2/3 upload ke baad root `index.html` nahi tha. Isliye website README ka `Brand-website-v2` heading dikha rahi thi. Old `app.js` aur `styles.css` bhi helper wrappers the; main website aur original images repo mein nahi aaye the.

## Upload steps
1. [Brand-website-v2](https://github.com/bhanu13yadav1-ai/Brand-website-v2) kholo aur current files ka backup/download rakho.
2. `V1_PHASE4_RECOVERY_UPLOAD.zip` extract karo.
3. Extracted `V1_PHASE4_RECOVERY_UPLOAD` folder ke andar jao.
4. **Us folder ke contents** GitHub repository ke root mein upload karo. ZIP file ko khud upload mat karna aur nested folder mat banana.
5. Root `index.html` add karo. Root `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` aur `README.md` replace hone do. `index.html`, `fallback.js`, `app-icon.svg` aur `phase4-diagnostics.html` add karo.
6. Sab files ek saath commit karo.
7. GitHub Pages build complete hone do. Phir website kholo.
8. Diagnostics kholo: `https://bhanu13yadav1-ai.github.io/Brand-website-v2/phase4-diagnostics.html` aur **Run full checks** dabao.
9. Fail ho to screenshot ya PASS/FAIL list bhejo. Live result dekhe bina website ko fixed declare nahi karenge.
